Project name – AgroTiny-C: A Quantized Decision-Tree Ensemble for Real-Time Crop-Stress Detection Using Multisensor Data 
Project description – A lightweight C program that evaluates five agricultural sensor inputs using threshold grouping and a three-tree majority-voting ensemble to detect and classify crop stress in real time.
Features – Input boundary validation (if guardrails), sensor state quantization (LOW vs. NORMAL/HIGH), modular decision-tree voting (tree1, tree2, tree3), majority-rule aggregation (votes >= 2), and specific stress diagnosis (water, heat, or combined stress).
Technologies used – C programming language,GCC Compiler.
How to run the program - gcc agrotiny.c -o agrotiny and execute using ./agrotiny (or agrotiny.exe on Windows).
